An interactive, operating-system-inspired personal portfolio for Aditya Kumar Jha.

Live site: https://aditya-os-portfolio.vercel.app/

## About

ADITYA.OS presents a profile through a desktop-like interface rather than a traditional portfolio layout. Visitors can explore my background, technical skills, projects, internships, hackathons, certifications, and contact details through a modern, responsive UI.

The project focuses on creative interaction, smooth motion, glassmorphism styling, ambient neon visuals, and accessible design.

## Features

- Interactive operating-system style interface
- Day and night theme toggle
- 16 accent color palettes
- Glassmorphism UI with ambient neon effects
- Responsive layout for desktop, tablet, and mobile
- Smooth animations powered by Framer Motion
- Dedicated sections for projects, deployments, internships, and hackathons
- Certificate gallery with full-size image preview
- Skills and technology showcase
- Interactive terminal with portfolio commands
- Live battery, network, and clock indicators
- Reduced-motion accessibility support

## UI Highlights

### Operating System Experience

The portfolio follows an OS-inspired visual concept, including:

- Desktop-style layout
- System navigation panel
- Glass effect cards
- Floating windows
- Developer dashboard aesthetics
- Status indicators
- Dynamic system footer

### Theme System

Visitors can personalize their viewing experience with a day or night theme and a choice of 16 accent palettes. Preferences are remembered in browser storage.

## Responsive Design
